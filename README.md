# case os

เว็บแอป (PWA) เตรียมและคุมเคสแข่งขัน เริ่มที่ **CMCC 2027** — หน้าตา/วิธีติดตั้งเหมือน Study OS
ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น (localStorage) ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มี Google Sheets

## ฟีเจอร์
1. **โจทย์ → สไลด์**: วางข้อกำหนดจาก booklet (1 บรรทัด = 1 ข้อ) ผูกกับเลขสไลด์ ข้อที่ยังไม่มีสไลด์ถูกธงแดง + ตารางเกณฑ์คะแนน/จำนวนหน้า
2. **เฟสและวันสำคัญ**: นับถอยหลังจาก 15 ม.ค. 2027 (แก้วันที่ได้) + เช็กลิสต์ gate 7 เฟสจาก case-workflow
3. **ตัวเลขต้องตรงกัน**: ใส่ตัวเลขหลักจากโมเดลครั้งเดียว บันทึกว่าไปอยู่สไลด์ไหนเขียนว่าอะไร ระบบเทียบให้ + เช็กผลรวม
4. **Q&A**: คลังคำถามกรรมการ + คำตอบสั้น + backup slide + โหมดซ้อมสุ่ม
5. **ก่อนส่ง**: เช็กลิสต์ (ดึงสถานะจากแท็บโจทย์/ตัวเลขอัตโนมัติ)
6. **คลัง**: pattern ทีมชนะ, บทเรียน KHC, stress test, โครง M&A (จากไฟล์ของเจ้าของ)
7. **สำรอง**: ดาวน์โหลด/นำเข้า JSON — **ล้างข้อมูลเว็บ = ข้อมูลหาย** ให้สำรองเป็นประจำ

แล้วเปิด `https://cheetos9250.github.io/case-os/` (Pages ฟรีต้องเป็น repo แบบ public — ในเว็บนี้ไม่มีข้อมูลส่วนตัว ข้อมูลอยู่ในเครื่องผู้ใช้)

เปิดบน iPad: Safari → แชร์ → เพิ่มลงหน้าจอโฮม · Samsung Chrome: เมนู ⋮ → เพิ่มลงหน้าจอหลัก / ติดตั้งแอป

## พัฒนา / ทดสอบ
```
node --test tests/*.test.cjs        # logic
node tests/browser.cjs              # Playwright (Chromium) ทุกแท็บ + สำรอง/นำเข้า + overflow
node tests/browser.cjs --shots out  # พร้อมภาพหน้าจอ
```
ไฟล์: `index.html`, `assets/logic.js` (ตรรกะล้วน), `assets/data.js` (เนื้อหาอ้างอิง), `assets/app.js`, `assets/app.css`, `sw.js` (ออฟไลน์)
ข้อมูลใน `data.js` มาจากไฟล์ case-workflow / winning-case-patterns / บทเรียน KHC เท่านั้น — ไม่มีข้อเท็จจริงเกี่ยวกับ CMCC นอกจากที่ไฟล์ระบุ
